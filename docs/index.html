      A short guide to writing a proof
      State the claim and its assumptions. Introduce each symbol before using it. Explain why each important equation follows, using full sentences and punctuation. Keep related ideas in paragraphs, then conclude the original claim.
      For induction, include a base case, the induction hypothesis, and the inductive step. For contradiction, state the negated claim and identify the contradiction.
      Based on Francis Su’s writing guide and AMS proof conventions.
      Write proofs and derivations. Check formal proofs with Lean.Math · reasoning · QED
